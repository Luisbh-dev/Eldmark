# Code of Conduct

Eldmark adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its Code of Conduct. It applies in all project spaces (issues, pull requests,
discussions and any official channel) and when someone represents the project in public.

In short: be respectful, welcome newcomers, accept constructive criticism, and do not
harass or demean anyone. Maintainers may remove comments, close threads or block people who
break these rules.

## Reporting

To report unacceptable behavior, contact the maintainer, [@Luisbh-dev](https://github.com/Luisbh-dev),
through GitHub. For a private report, open a private security advisory on the repository
(Security tab, "Report a vulnerability") and say clearly that it is a conduct report, or ask
for a private channel in a short public message without giving details. Reports are handled
confidentially.

Enforcement follows the guidelines in the Contributor Covenant linked above.
